# Text-to-Speech (TTS) Generator

A lightweight, interactive Web application that converts written text into spoken audio using JavaScript. Built with a clean interface and customizable speech settings.

---

## 🚀 Features

- 🔊 **Instant Text-to-Speech:** Convert any custom text into natural-sounding speech in real time.
- 🎙️ **Voice Selection:** Choose from multiple voices provided by the browser's SpeechSynthesis API.


## 🛠️ Tech Stack

- **HTML5:** Semantic structural layout
- **CSS3:** Custom styling and responsive UI
- **JavaScript (ES6+):** Application logic and Web Speech API implementation
